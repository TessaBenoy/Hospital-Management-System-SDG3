# CarePoint — Hospital Management System

A responsive, interactive front-end website created for the academic topic:

**Develop an Interactive Website for a Hospital Management System — SDG 3 (Good Health and Well-being).**

## Features
- Dashboard with patient, appointment, doctor and department summaries
- Appointment creation form with doctor, department, date and time
- Search appointments and filter by status
- Mark appointments as completed
- Patient directory with search and add-patient form
- Doctors directory and hospital departments
- Export appointment information as a CSV file
- Responsive layout for desktop, tablet and mobile
- Appointment and patient changes are saved in the browser using `localStorage`

## How to open in VS Code
1. Download and extract `CarePoint_Hospital_Management_System.zip`.
2. Open Visual Studio Code.
3. Select **File → Open Folder** and choose the extracted `hospital_management_system` folder.
4. Open `index.html`.
5. Right-click inside the file and select **Open with Live Server** (install the *Live Server* extension if needed).

You can also double-click `index.html` to open it in a browser, although Live Server is recommended.

## Important project note
This is a **front-end demonstration project**. It uses sample hospital data and browser `localStorage`; it does not include a real database, secure login, server, or actual patient records. Do not enter real or sensitive medical information. A production hospital system would require a secure backend, database, authentication, access control and privacy safeguards.

## SDG 3 connection
The project supports **United Nations Sustainable Development Goal 3: Good Health and Well-being** by demonstrating how digital tools can help organize appointments, make hospital services easier to navigate, and support efficient healthcare administration.
